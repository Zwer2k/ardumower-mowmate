# Release Notes v1.6.3

This patch release fixes the WiFi access point disappearing shortly after it started.

## WiFi

- The access point stays up in AP mode. The WiFi health check, meant to restore a lost connection to your home network, also ran in AP mode, where there is no such connection. Every 30 seconds it started a recovery that switched the radio back to client mode whenever home network credentials were stored, so the access point vanished before a phone or laptop could find it.
- The connection recovery now runs only in client (STA) mode. The restart on a fragmented heap still works in every mode.
- The access point log shows the default password as `"ArduMower Modem" (default)` when it is in use. It showed `(configured)` before, because the settings are pre-filled with the default values.

## Upgrade Notes

- Without a configured home network, or when the modem cannot reach it, the access point is still opened for 5 minutes only. Set the WiFi mode to AP to keep it on permanently.
