# Release Notes v1.16.0

This release brings Bluetooth LE, MQTT and Prometheus back to the ESP32 and adds a second ESP32 firmware for the PS4 controller. The web installer lets you choose between them.

## ESP32 firmware variants

- The ESP32 (without S3) comes in two variants, chosen in the **MowMate Web Installer** under **Firmware**:
  - **Standard**: Bluetooth LE for the app, MQTT with Home Assistant and ioBroker, and Prometheus. In v1.15.0 these were left out of the ESP32 to make room; leaving out the map code freed enough flash to bring them back (93 % of the flash).
  - **PS4 controller**: the PS4 controller instead of Bluetooth LE, with MQTT, Home Assistant and Prometheus.
- The ESP32-S3 is not affected: it has one firmware with everything, including maps.

## PS4 controller firmware

- Bluetooth Classic for the controller takes about 730 KB and does not fit next to a second firmware slot. The PS4 firmware therefore uses a different partition layout with one 3 MB firmware slot.
- **No online update.** The modem cannot update itself from GitHub or from an uploaded file; the firmware dialog says so and points to the web installer. Install new versions over USB. Mower firmware updates through the modem still work.
- **Settings are lost once** when a board switches between the standard and the PS4 firmware, in either direction, because the storage partition moves. Note the WiFi and mower settings first.
- The web installer shows these points when the PS4 firmware is selected. It is for the ESP32 only, not for the ESP32-S3.

## Updates

- Every variant looks for its own release file when it updates (`esp32-firmware.bin`, `esp32-ps4-firmware.bin`, `esp32-s3-firmware.bin`), so an online update never switches a board to the other variant.
- Releases now also carry the PS4 files (`esp32-ps4-*.bin`, `esp32-ps4.zip`), in the nightly builds as well. For releases before v1.16.0, the web installer reports the PS4 firmware as not available.

## Mow settings

- **Distance to border** and **Distance to exclusions** can now be set in steps of half a track width (0, 0.5, 1, 1.5 …). The route planner used to cut the distance to the border down to a whole number and rounded the distance to the exclusions, so a half step had no effect.
