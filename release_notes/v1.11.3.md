# Release Notes v1.11.3

This release makes the motor display on the main dashboard work with Sunray versions without motor telemetry, such as upstream Sunray.

## Main Dashboard

- The motor tile (rpm and current of the mow and drive motors) needs a Sunray that answers AT+S5. Without it, such as upstream Sunray, the tile showed 0 rpm and 0.00 A as if the motors were standing. It is now hidden, together with its chart.
- When Sunray does not answer AT+S5 three times while answering its status, the modem stops asking and checks again every 10 minutes; one answer is enough to treat it as supported for good. Unanswered requests held up the connection to the mower every 5 seconds before.
