# Release Notes v1.10.1

This release fixes lines along exclusions that still followed **Mow Border** instead of **Mow Excl. border**, and removes the gap below the buttons on phones.

## Exclusions

- Connections between the mow area and the exclusion laps follow **Mow Area** and **Mow Excl. border**. They are routed around exclusions, so they run along their edges, and they were shown and mowed only with **Mow Border** switched on.
- Exclusions that touch or merge with the perimeter get no separate lap; the perimeter laps run around them. The parts of those laps along the exclusion edge now count as exclusion laps and follow **Mow Excl. border** as well.
- In general, a connection between two kinds of lines is shown and mowed when both of them are switched on. The map editor, the dashboard map, the live map and the upload to the mower decide this the same way.

## User Interface

- On phones, the dashboards end exactly at the bottom edge of the screen. About 1 cm stayed empty below the buttons on some devices, because the calculated screen height did not match the visible area. The dashboards are now attached to the visible screen instead.

## Upgrade Notes

- Recalculate maps with exclusions so the laps along exclusions that touch the perimeter get their new category.
