# Release Notes v1.4.1

This patch release fixes GitHub firmware downloads and restores WebSocket reconnection after extended outages.

## Firmware Updates

- Fixed GitHub firmware updates failing with `Failed to fetch` because release assets do not permit browser cross-origin downloads.
- The ESP now downloads the target-specific firmware directly from GitHub and streams it into the OTA partition.
- Validates the release version and constructs the firmware URL on the ESP to prevent arbitrary download targets.
- Reports download and flash progress through the existing WebSocket status channel.
- Reports server-side download and installation errors to the update dialog.

## Connection Recovery

- Continues WebSocket reconnect attempts indefinitely instead of stopping after ten failures.
- Keeps the reconnect delay capped at 30 seconds to avoid excessive connection attempts.
- Removes the connection warning automatically when the WebSocket reconnects.

## Upgrade Notes

- The ESP requires internet access to download firmware from GitHub.
- Updating from v1.4.0 to v1.4.1 requires one final local firmware upload because the GitHub download path in v1.4.0 is blocked by browser CORS rules.
- Later releases can be installed directly through **Update firmware > GitHub Release**.
