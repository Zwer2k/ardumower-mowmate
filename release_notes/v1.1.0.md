# Release Notes v1.1.0

## Home Assistant / MQTT Integration

- **Complete overhaul** of the Home Assistant MQTT integration with ~33 entities.
- **Sensors**: Battery Voltage (1 decimal place), Temperature, Amps, GPS, Map CRC, Job State, Stats, Map Info (points, area).
- **Actors**: Buttons (Start/Stop/Dock/Skip Waypoint/Upload), Number (Speed), Select (Map with names).
- **Select Map**: Immediate state publication after map change — the selection no longer jumps back to the old value.
- **Uploaded Map**: Change detection ensures the uploaded map name is immediately available in HA after upload.

## Improvements

- **Remote Control**: A drop-down menu in the controller dialog with the option to set the settings as default.

## Bug Fixes

- **WebSocket Stability**: Fixed "Invalid frame header" and "Could not decode a text frame as UTF-8" errors by deferring hello messages during active map chunk transfers.
- **Live Map**: Map updates now properly trigger on state changes.
