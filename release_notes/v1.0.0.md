# Release Notes v1.0.0

This is the first release of **MowMate**, the standalone companion UI and control center for the ArduMower. It continues the work originally started as [ardumower-modem](https://github.com/timotto/ardumower-modem) with a broader scope: MowMate can now act as the primary web UI for the mower while keeping compatibility with external tools and apps.

## Rebrand and Repository

- Project renamed from **ArduMower Modem** to **MowMate**.
- New repository: [Zwer2k/ardumower-mowmate](https://github.com/Zwer2k/ardumower-mowmate).
- README, help dialog, firmware update links, and UI branding updated to the new name.
- Origin reference to Tim Otto and the original `ardumower-modem` repository preserved.

## Standalone Web UI

- MowMate now provides the primary browser-based UI for the ArduMower without requiring additional apps.
- Responsive embedded web interface served directly from the ESP32.
- Main dashboard with mower status, GPS overview, obstacle counter, and MiniMap.
- Status dashboard with detailed mower state, statistics, sensor data, and mower events.
- Map page for map editing, route review, and Sunray upload.
- GPS dashboard with satellite skyplot and detailed fix information.
- Live Map page with OpenStreetMap background and configurable track window.
- Remote control popover with virtual joystick, gamepad support, mower commands, and tuning controls.
- Log dashboard with filterable live output and CSV export.
- Terminal dashboard for interactive mower commands on supported ESP32-S3 builds.
- Motor test page for the 60-second motor ramp test.
- Settings page for WiFi, Bluetooth, MQTT, Prometheus, web, time, position, PS4 controller, and OTA updates.

## Map Workflow

- Persistent map model with perimeter, exclusions, dockpoints, waypoints, and Search Wire.
- Browser-based map editing with touch support, map rotation, naming, saving, loading, and deleting.
- Map persistence in SPIFFS, including map list management and metadata.
- Import and export in both Grauonline/ArduMower JSON and CaSSAndRA GeoJSON formats.
- Interception and local caching of maps transferred from the ArduMower App or CaSSAndRA.
- Route calculation directly on ESP32-S3 hardware with Lines, Squares, and Rings patterns.
- Sunray-compatible upload of perimeter, exclusions, dockpoints, and filtered mowing waypoints.
- Progress reporting over WebSocket for long-running operations such as route calculation and map upload.

## Route Tagging and Filtering

- Planner-generated waypoint tags for `AREA`, `BORDER`, `EXCLUSION_BORDER`, `CONNECTOR`, and `TRANSIT`.
- Runtime filtering with Area, Border, and Exclusion Border toggles.
- Tag-aware route visualization so hidden categories do not create misleading straight connector lines.
- Safe connector handling between route sections based on planner geometry.
- Search Wire support as a modem-only planning geometry for preferred safe connector paths.

## Connectivity and Integrations

- WiFi access point mode for first-time setup and station mode for normal operation.
- Bluetooth LE connectivity compatible with the original Sunray BLE workflow.
- HTTP and WebSocket-based UI communication served directly by the ESP32.
- MQTT support for status reporting and control.
- Home Assistant discovery and ioBroker integration.
- Prometheus endpoint for metrics collection.
- Browser gamepad support for manual control.
