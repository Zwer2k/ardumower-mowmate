# Release Notes v1.11.2

This release makes map uploads more reliable and makes the **Mow areas** switches count in the map's point numbers and sync check.

## Map Upload

- Map uploads no longer fail with "The mower stopped accepting map points" when the mower answers a map chunk late. The late answer was taken as the answer to the next chunk and looked like the mower refusing points, so uploads often failed on the first try and worked on the second. The modem now waits 1.5 seconds before resending a chunk, and only reports that the mower stopped accepting points when it refuses the same chunk again.
- The point counts on the map (**Total** and **Way**) show the points that go to the mower. Waypoints of switched-off **Mow areas** (Area, Border, Excl. border) are not uploaded and no longer counted; **Way** shows the calculated number next to it, e.g. **Way: 210 / 344**. The memory estimate uses the same number.
- The map CRC that the modem expects from the mower now also depends on the **Mow areas** switches. Before, it always included all waypoints, so a map uploaded with an area switched off showed as **not synced** (for example after restarting the modem) and was not marked **on mower** in the map list. Saved maps get the corrected CRC when they are loaded.

## Map

- A single click on the map no longer sets a **Go to** target. The first click only selects the map and shows **Tap again to set a go-to target** for 2.5 seconds; a second click within that time sets the target, later clicks need two clicks again. This avoids targets set by accident while panning or after closing a menu.
- **Go to** on the map hides itself when the mower has reached the target: once the mower stops within 0.6 m of it after driving there, the target marker and the Drive/Stop buttons disappear. If the drive ends elsewhere (cancelled or an error), the target stays for a new try.
- The distance and direction to the target next to the Drive button now follow the mower; they always showed 0.0 m / 0° before.
- Drive, Stop and ✕ sent their command to the mower twice.

## Mower Settings

- **Cutter speed** no longer drops to 0 % after a MowMate restart. The modem follows the commands it sends to the mower to know the current settings, and read the checksum of short commands (start, stop, dock, sonar) as the cutter speed, which made it 0. The saved default is kept now. The tuning command (AT+CT) was also mistaken for a control command.
- Until a cutter speed is saved with **Set as Default**, MowMate uses 70 %. Settings from earlier versions keep a saved cutter speed, unless it is 100 %: earlier versions stored 100 % with every settings change, so that value cannot be told apart from never saved and now becomes 70 %. Save it again with **Set as Default** if you want 100 %.
