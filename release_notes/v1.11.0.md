# Release Notes v1.11.0

This release adds settings for the terminal port with automatic baud rate detection, brings back the title and close button of dialogs on the dashboards and lets MowMate use the full screen height on Android phones.

## Terminal

- New settings group **Terminal** for the serial port to the mower console: **Baud rate** (Auto or 9600 to 921600) and **Data format** (8N1, 8E1, 8O1). The port was fixed to 115200 8N1.
- With **Auto**, the modem starts at 115200 baud. When unreadable data arrives, it listens briefly at each common baud rate and keeps the first one at which readable text arrives. This needs output from the mower; the settings show the detected baud rate. The data format cannot be detected, since parity does not change how text looks.
- After a mower firmware update the terminal port returns to these settings. The STM32 bootloader left it at 115200 8N1. The upload always uses 115200 8E1 itself, independent of these settings, and stops a running baud rate detection.
- New mower capability **Terminal**. When the terminal port is not wired, switch it off: the port stays off and the Terminal dashboard and settings are hidden.

## User Interface

- Dialogs opened from a dashboard, such as **Route check**, **Mow Settings** or the map management dialogs, show their title and close button again. Since v1.10.1 the header bar covered them.
- On Android phones with gesture navigation, the dashboards now reach down to the gesture bar. Chrome kept the area of the navigation bar free, which looked like about 1 cm of empty space below the buttons. The page now draws behind the bar and keeps its buttons just above it. This needs Chrome 135 or newer on Android 15; other browsers stay as before.
- In landscape, the header and the dashboards keep clear of a camera notch at the side of the screen.
