# Release Notes v1.4.0

This release adds integrated modem firmware updates from GitHub, improves connection recovery and diagnostics, and fixes release packaging for both supported ESP targets.

## Firmware Updates

- Added firmware updates to the main header overflow menu and highlights the entry when a newer stable modem firmware release is available.
- The ESP downloads target-specific modem firmware directly from GitHub and streams it into the OTA partition, avoiding browser CORS restrictions.
- Selects the latest compatible release by default while allowing installation of older compatible versions.
- Filters release assets by the connected modem target to prevent cross-flashing ESP32 and ESP32-S3 firmware.
- Validates release versions and constructs the fixed GitHub download URL on the ESP to prevent arbitrary download targets.
- Reports download and flash progress through the existing WebSocket status channel.
- Reports HTTP, transport, TLS, stream, and flash errors directly in the update dialog.
- Includes the USERTrust ECC root certificate required by GitHub's current Sectigo TLS chain.
- Keeps local file uploads available for modem firmware and Sunray mower firmware.
- Shows GitHub as an update source only for modem firmware; Sunray mower firmware still requires a local BIN file.
- Retries update discovery after the modem connection becomes available.
- Hides the local file size field for server-side GitHub downloads.

## Connection Status

- Added a persistent warning when the ESP modem or its WebSocket connection is unavailable.
- Delays the initial warning briefly to avoid showing it during normal page startup.
- Removes the warning automatically after the connection is restored.
- Continues WebSocket reconnect attempts indefinitely, with the retry delay capped at 30 seconds.

## Diagnostics

- Added detailed GitHub OTA logging for DNS resolution, HTTP responses, native TLS errors, response size, stream interruptions, and flash failures.
- Added RTC/NTP logging for configured servers, DNS resolution, UDP requests, response metadata, `settimeofday`, epoch, and formatted local time.
- Keeps errors visible at every modem log setting except communication-only mode.
- Applies cumulative severity filtering so debug and info modes include warnings, errors, and critical messages.

## Header Actions

- Moved firmware updates and device restart actions into the main header overflow menu.
- Added a Restart submenu for restarting the modem, mower, or GPS receiver.

## Release Packaging

- Fixed GitHub releases missing classic ESP32 firmware artifacts.
- Builds and packages the reduced UI for classic ESP32 and the complete Map, Live Map, and GPS UI for ESP32-S3.
- Fails the CI release job when expected firmware artifacts are missing instead of publishing an incomplete release.
- Updated GitHub Actions to Node.js 24 compatible versions.

## ESP32 OTA Support

- Changed the classic ESP32 partition layout to provide two OTA application slots.
- Existing ESP32-S3 OTA behavior remains unchanged.

## Upgrade Notes

- The GitHub updater installs modem firmware only. Sunray mower firmware must still be selected as a local BIN file.
- The integrated updater becomes available after v1.4.0 has been installed once using the existing manual update process.
- The ESP requires internet access and a synchronized system clock to validate GitHub TLS certificates.
- Firmware assets are selected using the modem target reported by the device; no manual ESP32 or ESP32-S3 selection is required.
