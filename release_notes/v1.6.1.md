# Release Notes v1.6.1

This patch release makes the WiFi access point log tell you how to connect to the modem.

## WiFi

- When the access point starts, the log shows SSID, password, IP address, MAC address and channel as one block, one value per line. Previously it showed only the IP address, so a freshly flashed modem gave no hint which network to join.
- The built-in default password is printed in plain text, since it is public anyway. A password you configured yourself appears as `(configured)`, because the log is also visible in the web UI.
- A failed access point start, for example because the configured password is shorter than 8 characters, is now logged as an error instead of being ignored.
