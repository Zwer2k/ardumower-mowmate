# Release Notes v2.4.0

This release adds a fully integrated mowing scheduler, time settings in the web UI, and several UI/UX refinements.

## Summary of changes since v2.3.1

- 19 files changed, ~1890 insertions, 55 deletions
- 3 commits on top of v2.3.1

## Scheduler

### New

- **Mowing scheduler backend**
  - New domain manager `src/domain/schedule.*` persists mowing plans in SPIFFS.
  - Supports daily, weekly, and monthly schedule entries, each with a start time and a target map.
  - Automatically computes the next scheduled run and exposes it to the UI.
  - New WebSocket messages (`setSchedule`, `saveSchedule`, `requestSchedule`) connect the backend to the web UI.

- **Schedule UI in map toolbar**
  - New `Schedule` panel in the map toolbar (`ui/src/map/toolbar/MapScheduleToolbar.svelte`).
  - Create, edit, and delete appointments linked to the currently selected map.
  - Enable or disable the scheduler with a toggle.
  - Weekday and monthday selection with clear visual distinction between selected and unselected days.

### Fixed

- The schedule save button was incorrectly active immediately after a page reload.
  - The Carbon Checkbox component fires `on:check` during mount; these events are now ignored when the value has not changed.
  - The backend echoes every local schedule change back to the UI; the UI store now tracks the last sent draft and ignores those echo broadcasts, so user-made changes stay dirty until the user explicitly saves.

## Time Settings

### New

- **Time settings in the web UI**
  - New `Time` settings panel (`ui/src/settings/Time.svelte`) for NTP and timezone configuration.
  - Settings are integrated into the existing settings list and persisted via the backend (`src/domain/settings.*`).
  - WiFi adapter extended to handle NTP/time settings (`src/comm/wifi_adapter.*`).

## UI / UX Improvements

- **Map toolbar tooltips**
  - Icon-only buttons in the top map toolbar now show their tooltips above the button row, avoiding clipping by the page header.

- **Next run display on dashboard**
  - The main dashboard shows the next scheduled mowing time and target map when the scheduler is enabled.

- **Map panel visibility**
  - The canvas is hidden while the schedule or other panels are open, giving the schedule editor more space.

## Backend / Communication

- Extended WebSocket protocol with schedule and time-setting request/response types (`ui/src/model.ts`, `ui/src/stores/socket.ts`, `src/comm/ui_adapter_socket.*`).
- Updated `platformio.ini` for the new build configuration.
- Wired the new schedule manager into the main application (`src/esp_modem.cpp`).
