# Release Notes v2.5.0

This release improves positioning, live map rendering, map creation workflow, and remote control handling.

## Position Settings

- New `Position` settings panel for `relative`/`absolute` mode with persisted reference lon/lat.
- Firmware sends `AT+P` on boot with saved mode and coordinates.
- New `NumberSetting` widget preserves numeric values.

## Live Map

- Fixed marker rendering in relative/absolute mode.
- Added fallback to mower `x/y` track when UBX PVT is unavailable.
- Faster status bar updates via mower position fallback.

## Map Workflow

- Fixed new map creation crash by adding `reset()` to compass state.
- Cancelling a new map now discards it and selects a fallback map.
- Fixed race during `mapList` loading that could leave no selected map.
- Renamed "CassandRA map" to "Mower Map".

## Map Editing & Path Planner

- Added `MowAreaToggles` for per-area enable/disable controls.
- Touch-friendly point dragging without accidental panning.
- Path planner fixes and better exclusion handling.
- Map export format aligned with the Ardumower app.
- Map cached in browser `localStorage` to avoid re-transfer on reconnect.

## Remote Control

- Added gamepad support for remote control.

## Backend / Communication

- Added 10 cm minimum distance filter to `DrivenTrack`.
- WebSocket stability improvements (fewer EPIPE errors, less flickering).
- Detailed CRC logging for map upload diagnostics.

## Maintenance

- Added `release_notes/v2.5.0.md`.
