# Release Notes v1.6.2

This release changes only the build pipeline. The firmware is identical to v1.6.1.

## Web Installer

- The web installer no longer loses its stable channel after a release. Pushing a release tag together with `main` started two builds; the one for `main` picked the new release before its files were uploaded and published an installer that reported "No firmware has been published for this channel yet".
- The stable channel now uses the newest release whose installer files are all uploaded, and falls back to the previous release while a new one is still being published.
- A commit that carries a release tag is published by the tag's own build, after its release is complete.
