# Release Notes v1.6.4

This patch release makes the WiFi access point visible on boards where phones and laptops could not find it.

## WiFi

- The access point now sends at 8.5 dBm instead of 20 dBm. On some ESP32-S3 boards the access point started without errors, but no device listed it: at full power these boards send beacons that phones and laptops cannot decode.
- Client (STA) mode is unchanged and still uses full transmit power.

## Upgrade Notes

- The access point has a shorter range than before. Set up the modem from close by.
