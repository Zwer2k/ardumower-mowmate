# Release Notes v1.12.1

This release makes sure the cutter runs after **Start**, keeps your mowing settings when starting and shows why the mower stopped as a coloured badge.

## Dashboards

- The status tile on the main dashboard shows why the mower stopped as a coloured badge instead of the text "Meldung: …": red for errors and safety stops (e.g. **kidnapped**, **lift**, **motor error**), magenta for obstacles and GPS problems, cyan for **rain**. The status dashboard uses the same colours; it showed every reason in red before.

## Mowing

- **Start** releases the mow motor. Sunray locks the mow motor after any control command that switched it off and keeps it locked until it restarts; a mowing run started from MowMate then drove without the cutter, while the motor test still worked. If the mow motor was switched off on purpose before (e.g. Home Assistant fan speed **off** to drive without cutter), Start keeps it off.
- **Start** no longer overwrites the mowing settings. It used to set 0.2 m/s, a GPS fix timeout of 100 s, "finish and restart" off and the sonar on with every start.
- The **Mow Motor** control on the status dashboard is a switch with three positions, **Off | Auto | On**, instead of a checkbox that had to be clicked through its states. **Off** switches the cutter off and keeps it off, also when mowing starts; **Auto** lets Sunray switch it on and off while mowing; **On** switches it on now. The switch shows the state the modem knows, also after reloading the page.
- **Auto** no longer switches the cutter on. It sent the same command as On, so the cutter started, and kept running while the mower was idle. Now Auto releases the cutter while mowing and otherwise leaves it to the next start.
