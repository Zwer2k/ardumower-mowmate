# Release Notes v1.3.0

This release improves map synchronization and adds round-trip compatibility with original CaSSAndRA GeoJSON maps.

## Map Synchronization

- Bound edits, settings, and uploads to the active map and exact accepted revision.
- Fixed Lines and Rings settings being mixed between maps.
- Unified synchronization status across the map editor, Main Dashboard, and MiniMap.
- Compare Sunray against the CRC of the actual filtered upload instead of the complete stored map.
- Replaced unnecessary full map retransmissions with compact acknowledgements.

## Route Selection

- Area, Border, and Exclusion Border switches now filter routes without recalculating or modifying the complete map stored in memory and SPIFFS.
- Sunray receives exactly the route selected by the switches while the complete editable map remains intact.
- Limited driven-track history to 50 points and added incremental updates.

## CaSSAndRA Compatibility

- Import and export original CaSSAndRA GeoJSON maps with WGS84 coordinates.
- Preserve perimeter, exclusions, Dockpoints, and Search Wire in the expected CaSSAndRA feature structure.
- Automatically detect GeoJSON and show imported geometry immediately.
- Reject missing or implausible Position references instead of producing a clustered or blank map.

## Upgrade Notes

- Existing MowMate and SPIFFS maps remain compatible; no migration is required.
- Original CaSSAndRA GeoJSON files do not contain their local coordinate origin. Import and export therefore require the same longitude/latitude reference under **Settings > Position** that CaSSAndRA used for the map.
