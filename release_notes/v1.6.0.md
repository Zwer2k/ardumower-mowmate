# Release Notes v1.6.0

This release adds cutter speed control and live motor data, makes the mower settings survive a mower reboot, and introduces a browser-based installer that flashes a board without a local toolchain. It also fixes a defect that could overwrite the wrong map when the modem restarted during editing, and makes stored data survive a power loss during a save.

## Map Editor

- A modem restart while editing no longer overwrites the wrong map. Unsaved edits live only in the modem's RAM; after a restart it loads its default map, and the editor kept sending its edits under whatever map the modem reported, so saving wrote them into the default map.
- The editor now pins the map it is editing. Edits and saves always go to that map, and the save request carries the map id, so the modem refuses to save a request meant for another map.
- After a reconnect the editor restores the map it was editing and re-sends its changes, retrying while the modem is still busy. A message confirms the restore; save to keep the changes.
- The Save button stays enabled after a restore. The modem reports the reloaded map as clean until the changes arrive, and that report used to clear the unsaved state; a stale reactive value could also leave the button disabled until the page was reloaded.
- If the edited map cannot be restored (a new map that was never saved, or five failed attempts), editing stops with a message and the current map is reloaded. Nothing is written to another map.
- After a reconnect the map is transferred once instead of twice, and loading a map no longer fails while a transfer to the browser is still running.
- The goto target controls appeared both in the toolbar and on the map. The toolbar copy is gone; the controls on the map remain.

## Data Safety

- Settings, the mowing schedule, the map index and map files are written atomically. A power loss during a save, for example when the battery runs empty, used to leave a truncated file: a broken map index made every map disappear, a broken settings file fell back to defaults including the WiFi credentials. Now either the old or the new content survives.
- A full flash filesystem is reported as a failed save. Previously a truncated file counted as saved.
- Renaming a map whose file could not be read replaced the whole map with nothing but its name and metadata. The file is now left untouched.
- `AT+W` waypoint commands with a negative index or a jump of more than 1000 points are rejected. A negative index wrote outside the waypoint buffer, and a huge one exhausted the heap.

## Remote Control

- Added a cutter speed slider (10–100 %). It sets Sunray's mow motor PWM limit (`AT+C` field 9); the conversion from percent stays in the UI.
- Fixed the mow height slider, which had no effect: it sent `AT+S2`, which Sunray treats as an obstacle list request and ignores. It now uses the actual setter, `AT+C` field 10.
- The Sonar checkbox shows the last state that was sent. It always showed "off" because the popover is rebuilt on every open and the state was never tracked. Note that this switch also controls the bumper's near-obstacle detection in Sunray.
- The waypoint position is set with five decimals instead of two. Two decimals moved the target in steps of 1 % of the route, which is 50 waypoints on a 5000-point map.
- Clicking the waypoint percentage opens a field for the exact waypoint number, and the +/- buttons move exactly one waypoint. The value follows the mower's progress only while it is mowing, so it no longer overwrites a target you picked, and it survives closing the popover.
- Clicks on controls that remove themselves no longer close the popover.

## Mower Settings

- Speed, fix timeout, finish & restart, cutter speed and mow height are re-sent once after the modem has connected to the mower. Sunray keeps them only in its SD state file, which most boards never restore (the MOW800 has no SD slot), so they were lost on every mower reboot.
- Cutter speed and mow height are stored with the other mower settings, and "Set as Default" saves the values that were actually commanded.
- New "Mower capabilities" settings — cutter speed, cutter height, sonar — hide the controls for hardware the mower does not have. Sunray does not report its capabilities, so they are declared here. All are enabled by default; existing installations are unchanged. "Reset to Defaults" keeps them.

## Dashboard

- Added live motor data: RPM of both wheels and the mow motor, mow motor PWM and motor currents, polled every 5 seconds (`AT+S5`).
- A history chart on the main dashboard covers a whole mowing run. The buffer holds 240 samples and halves its resolution when full, so it never allocates during a run.
- The data is also available at `GET /api/robot/motor_rpm`.

## Firmware Updates

- The firmware dialog no longer switches to the GitHub source while a file upload is running. A release list arriving mid-upload used to flip the view and hide the upload progress.

## Web Installer

- Boards can now be flashed from a desktop Chrome, Edge or Opera over Web Serial, without installing a toolchain. The installer is published on GitHub Pages and detects whether an ESP32 or ESP32-S3 is connected.
- A switch selects the stable release or the nightly build.
- Every release now includes `boot_app0.bin`, which the installer needs.
- See `docs/web-flasher.md` for flash offsets and browser requirements.

## Build

- Removed the unused Concourse CI pipeline inherited from the original import. CI runs on GitHub Actions only.

## Upgrade Notes

- The web installer asks "Erase device?" on every flash. Leave the checkbox unticked to keep maps, schedules and settings; ticking it wipes them together with the WiFi credentials.
- If your mower has no sonar, no cutter height adjustment or no cutter speed control, disable the matching entry under "Mower capabilities" to hide the control.
- Overwriting a map now briefly needs space for the old and the new file at once. On an almost full filesystem a large map can fail to save; the previous version stays intact and the log reports the error.
- Cutter speed and mow height are applied to the mower after every modem restart. Check the stored defaults if the mower suddenly mows with a different height or speed.
