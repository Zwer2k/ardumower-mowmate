# Release Notes v1.10.0

This release separates the laps around exclusions from the perimeter laps: they get their own lap count and distance and are switched on and off with **Mow Excl. border**. The GPS dashboard now shows correct and up-to-date values without disturbing the mower's own GPS reception. "Reset to Defaults" in the remote control restores your own defaults again.

## Exclusions

- The laps around exclusions are now switched with **Mow Excl. border**. They were treated as perimeter laps: "Mow Excl. border" did not hide them, and "Mow Border" switched them together with the perimeter laps.
- New mow setting **Exclusion laps**: the number of laps around each exclusion, independent of **Border laps**. Each further lap lies one track width further out; before, all laps around an exclusion ran on the same line.
- New mow setting **Distance to exclusions**: how many track widths the mow area keeps away from the exclusions. **Distance to border** only applies to the perimeter now; before, exclusions inside the area got no distance at all.
- Maps saved or exported with earlier versions keep their behaviour: as many laps around each exclusion as around the perimeter, and no distance to the exclusions.
- Exclusions that touch or merge with the perimeter get no separate laps. The perimeter laps run around them.

## GPS Dashboard

- The modem asks the GPS receiver for dashboard data at most once per second. Every query blocked the mower's GPS processing for up to half a second, and the dashboard sent them back to back, so the mower lost position updates while the GPS dashboard or the live map was open. Sunray needs the matching change (branch `add-AT+UBX-AT+S3-AT+S4`), which no longer blocks at all.
- GPS details are only requested while the GPS dashboard or the live map is open, every 5 s. They were requested every 20 s for all clients, and the first values could take up to 20 s to appear.
- Navigation status, deviation map and altitude chart update continuously. They stayed at their first values.
- After a WiFi interruption or a modem restart, the dashboard and the live map receive data again without reloading the page.
- Satellites marked as used, satellite health, the satellite count of NAV-SAT and the DOP values were decoded from the wrong bytes and are correct now. Signal quality labels follow the u-blox definition (unusable, code locked, carrier locked).
- Positions without a fix no longer enter the deviation map; a single 0/0 position made it draw millions of rings and froze the browser tab.
- New **RTK history** of the last 30 minutes: Fixed, Float and no RTK over time, the fixed share and the number of fix losses.
- A warning appears when the connection to the modem is lost or no GPS data arrived for 15 s, and the status bar shows when the values were updated.
- The satellite table shows one row per satellite with the signal bands (L1, L2, E1, E5b, B1I, ...). The sky plot only uses real satellite positions, and the altitude chart shows the height above sea level.
- The Advanced (UBX) view decodes NAV-SAT, NAV-SIG, NAV-STATUS, HPPOSLLH, MON-VER, MON-HW, MON-RF, MON-COMMS and RELPOSNED correctly. The configuration cards show the active receiver configuration instead of its factory defaults, with valid keys for UART1 baudrate, SBAS, RTCM input and UART1 protocols.

## Remote Control

- **Reset to Defaults** restores the values saved with **Set as Default**. It reset the mower settings to factory values instead (cutter speed 100 %, speed 0.3 m/s) and overwrote the saved defaults.
- The menu closes at once and reports the result; it waited 1-2 s before. After **Set as Default**, the settings page shows the new defaults.
- The speed, fix timeout, cutting height and cutter speed sliders follow changes made elsewhere, for example by **Reset to Defaults** or another browser, while the remote control is open.
- The command log shows the sent value, for example `sonarEnabled: off`. Switching sonar off looked like switching it on.

## User Interface

- On phones, the dashboards fit the visible screen. With the browser's address bar shown, the buttons at the bottom were pushed below the screen.
- **Show password** no longer reveals a placeholder such as 999999 for a stored password. The modem never sends stored passwords to the browser, so the button only appears while a new password is typed.

## Upgrade Notes

- Recalculate maps with exclusions. Their waypoints still carry the old categories, so **Mow Excl. border** only takes effect after a new calculation.
- For the GPS dashboard fix to fully take effect, update Sunray as well (branch `add-AT+UBX-AT+S3-AT+S4`).
