# Release Notes v1.11.1

This release lets MowMate work with Sunray versions that do not report the sensor summary, such as upstream Sunray, and shows on the main dashboard why the mower stopped.

## Sensors

- Works with Sunray versions without the sensor summary (AT+S3). When Sunray does not answer AT+S3 three times while answering its status, the modem stops asking and checks again every 10 minutes; one answer is enough to treat it as supported for good. Unanswered requests held up the connection to the mower every 5 seconds before.
- Without the sensor summary, the dashboards show **Sonar triggered** for 30 seconds after Sunray counts a sonar event in its statistics, with the number of events. Sonar distances, bumper, lift, rain and LiDAR need a Sunray with AT+S3 and are hidden.

## User Interface

- The status tile of the main dashboard shows why the mower stopped last, for example **Meldung: rain** when rain interrupted mowing or **obstacle** after an obstacle. The status dashboard already showed this reason.
